# Route 02 – Neo‑Brutalist

Creative direction
- Loud, graphic, structural. Big type, hard edges, visible borders/constraints. Utility-first feel.
- Tone: bold, opinionated, confident. Embrace asymmetry and raw web UI elements.

Color palette
- Ink: `#0F1115` (text, borders)
- Canvas: `#F5F5F0` (background)
- Lime: `#00F6A2` (primary accent)
- Magenta: `#FF3B81` (secondary accent)
- Electric Blue: `#5B8CFF` (interactive, focus)

Typography (Google Fonts)
- Display/text: [Bricolage Grotesque](https://fonts.google.com/specimen/Bricolage+Grotesque) or [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk)
- Mono for code/badges: [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) or [IBM Plex Mono](https://fonts.google.com/specimen/IBM+Plex+Mono)

Type scale
- H1 72/72, H2 44/48, H3 28/32, Body 18/28, Small 14/20, Button 16/18

Layout patterns
- Bento grid tiles. Thick borders (2–3px), high-contrast sections. Sticky sidebar or top nav with chunky tabs.
- Card stacks with labels, chips, and visible focus states.

Motion/interaction
- Snappy. Scale/translate micro-interactions, springy easing, 150–220ms.
- Deliberate hover states: underline from left, background pop, border color shift.

Components to define
- Nav with tabs/pills, button set (solid lime, outline ink, ghost), tag chips, badge counters.
- Project tiles with big typography overlays; filter/sort controls.

Copy/voice
- Direct, declarative, energetic. Short sentences, active voice.

References
- Awwwards/Dribbble: neo‑brutalism and bento grid layouts
- Cargo/Framer/Webflow showcases with chunky UI

Do
- Use visible grid and borders
- Use high color contrast thoughtfully
- Keep spacing generous to avoid clutter

Avoid
- Subtlety to the point of blandness
- Over-animated noise; keep interactions purposeful
