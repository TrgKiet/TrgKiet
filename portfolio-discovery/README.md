# Portfolio Discovery

This workspace contains three distinct art-direction routes for your portfolio. Each route includes a moodboard, palette, typography guidance, layout patterns, motion notes, and references.

- route-01-editorial-minimal: Clean, editorial feel with refined typography and restrained color.
- route-02-neo-brutalist: Loud, graphic, chunky UI with bold color and visible structure.
- route-03-dark-lux: Dark, cinematic, premium feel with muted metallic accents.

How to use
1) Open `index.html` to preview palettes quickly.
2) Read each route's `README.md` to understand the look/feel and see references.
3) Pick a direction, then we can translate it into a component library and page layouts.

Next steps after choosing a route
- Lock color tokens and type scale
- Define UI kit (buttons, cards, project tiles, nav, footer)
- Draft homepage and one project page wireframe
- Build v1 in code with the chosen direction
