# Moodboard Guide

Goal
Collect 30–50 visual references per route to validate direction: color, type, layout, motion.

Sources
- Awwwards (filter by minimal, brutalist, dark)
- Behance (search: "editorial web", "neo brutalism", "dark luxury website")
- Dribbble (search: "bento grid", "brutalist ui", "editorial typography web")
- Studio sites you admire; product marketing pages with strong art direction

What to capture
- Homepage hero treatments
- Project tiles/grids
- Type pairings and sizes
- Color usage ratios (neutral vs. accent)
- Interaction/scroll patterns

How to collect quickly
1) Create folders in `assets/` for each route (01, 02, 03).
2) Screenshot or save images; name descriptively, e.g., `01-hero-type-ny-studio.png`.
3) Add a one‑line note per image: why it works.
4) Cull down to the strongest 12–15 per route.

Evaluate
- Does the direction communicate your 3 brand adjectives?
- Is there a consistent color ratio and type hierarchy?
- Are accessibility and readability preserved?

Output
- Curated board per route with 12–15 images + 3 bullets on why this direction fits you.
