# Route 03 – Dark Lux

Creative direction
- Dark, cinematic, premium. Subtle textures, soft contrast, restrained metallic accents.
- Tone: sophisticated, reflective, deliberate.

Color palette
- Night: `#0B0C10` (primary background)
- Charcoal: `#1A1C1F` (surfaces, cards)
- Gilt: `#C6A769` (accent, dividers, icons)
- Slate: `#6E7A86` (muted text, strokes)
- Deep Teal: `#2B8C7E` (secondary accent for links/hover)

Typography (Google Fonts)
- Serif display: [Cormorant Garamond](https://fonts.google.com/specimen/Cormorant+Garamond) 600/700 for H1–H2
- Sans text/UI: [Manrope](https://fonts.google.com/specimen/Manrope) or [Inter](https://fonts.google.com/specimen/Inter) for body and UI

Type scale
- H1 56/64, H2 36/44, H3 24/32, Body 18/28, Small 14/22, Button 16/20

Layout patterns
- Edge-to-edge hero with subtle gradient. Cards on charcoal with fine 1px strokes in slate/gilt.
- Masonry or carousel for project imagery; immersive case studies with dark canvas and high-res images.

Motion/interaction
- Smooth, slow. Opacity/blur reveals, parallax on hero, 250–350ms easing. Hover lines glow slightly in gilt.

Components to define
- Top nav with contrast-aware states, pill buttons (gilt outline, teal hover), stat blocks, testimonial carousel.

Copy/voice
- Understated, confident, thoughtful. Focus on craft and results.

References
- Awwwards – dark theme portfolios
- Behance – luxury branding websites
- Premium studio sites with dark/cinematic direction

Do
- Keep contrast comfortable; avoid pure white text on black (prefer slate)
- Use gilt sparingly for highlights and dividers
- Use subtle depth (1–2px borders, soft shadows)

Avoid
- Overuse of gradients and glow
- Neon colors that break the mood
