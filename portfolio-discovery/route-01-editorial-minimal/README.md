# Route 01 – Editorial Minimal

Creative direction
- Clean, typographic, editorial. Inspired by Swiss/modern editorial design and high-end magazines.
- Tone: confident, calm, intelligent. Let content breathe. Make images large and typography impeccable.

Color palette
- Ink: `#111216` (primary text, lines)
- Paper: `#F8F7F4` (background)
- Parchment: `#EAE7E0` (secondary background, cards)
- Cobalt: `#0A84FF` (primary accent, links)
- Vermilion: `#E14B2E` (secondary accent for small highlights)

Typography (Google Fonts)
- Serif display: [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4) for H1–H3
- Sans text/UI: [Inter](https://fonts.google.com/specimen/Inter) for body, nav, buttons
- Optional alt pairing: [Fraunces](https://fonts.google.com/specimen/Fraunces) + [Work Sans](https://fonts.google.com/specimen/Work+Sans)

Type scale (starting point)
- H1 56/64, H2 40/48, H3 28/36, Body 18/28, Small 14/22, Button 16/20

Layout patterns
- Generous margins and whitespace. 12-column grid with wide gutters.
- Editorial hero: large headline + supporting dek + single call-to-action.
- Project listing: big image tiles with concise 1–2 line summaries. Use hover caption reveals.
- Asymmetric image + text blocks, alternating.

Motion/interaction
- Subtle. Fade/slide-in at low distance, 200–300ms. Link underline grow on hover. Smooth scroll to anchors.

Components to define
- Nav (top, sticky after scroll), footer with compact contact block
- Button styles (primary cobalt, secondary outline)
- Project tiles, case study template (hero, role, timeline, process, gallery, outcomes)

Copy/voice
- Clear, precise, modest but confident. Emphasize outcomes and decision-making.

References
- Awwwards – minimal/editorial portfolios
- Behance – editorial web layouts
- Inspo: studios with clean grids and restrained color

Do
- Use plenty of white space
- Keep color mostly neutral, accents sparing
- Prioritize readability and hierarchy

Avoid
- Overusing color accents
- Heavy shadows or glassmorphism
- Excessive motion
